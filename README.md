# IMFAO
Import Multiple Fixtures At Once<br>
This is a Lua plugin written for the grandMA2<br>
It allows you to load multiple fixture types from a folder into the showfile at once.<br>
Unfortunately, I haven't yet managed to have the MA2 automatically read the XML filenames; this Lua function appears to be restricted.<br>
Therefore, the filenames must be entered into a list within the code. I took a screenshot and had an AI generate the list for me.<br>
I am open to better ideas.<br>
